# Botlien

Private repo combining Botlien's business materials and product codebase in one place. Founders: Antonio D'Angelo (CEO) · Samuel Kim (CTO).

## Where things are

| Folder | What's in it |
|---|---|
| **`demo/`** | The actual product. Samuel's telemetry pipeline, rules engine, dashboard, and tests, originally at `samk0228/botlien`, now living here. See `demo/README.md` for architecture, quick start, and how to run it. |
| **`website/`** | Source for botlien.com, a Cloudflare Worker. `website/public/` is the live site, `website/src/index.js` is the worker. |
| **`deck-export/`** | Live working files for the pitch deck editor. Not a finished deliverable, the actual shareable deck PDF lives in `01 Venture Ready Materials/Pitch Deck/`. |
| **`01 Venture Ready Materials/`** | Finished, polished, ready-to-share material: the pitch deck, legal documents (NDA, Data Access Agreement), and fundraising documents (SAFE, cap table, round summary). |
| **`02 Docs/`** | Working notes, drafts, and trackers, Build.md, discovery tracker, deck design prompt, case study draft. |
| **`03 Legal & Business Docs/`** | Source PDFs, blueprint exports, original NDA template. |
| **`04 Logos/`** | Brand assets. |
| **`05 Reference Images/`** | Reference imagery. |
| **`06 Archive/`** | Superseded versions, kept for reference only. |

## Why some folders are numbered and some aren't

The numbered folders (`01` through `06`) are business documents and reference material, numbered so they sort in priority order instead of alphabetically. `demo/`, `website/`, and `deck-export/` are active tools and source code, not static documents, so they're left unnumbered and sort after the numbered ones.

## Status

Pre-seed, pre-incorporation. Botlien has not yet completed formation as a Delaware corporation, several fundraising documents in `01 Venture Ready Materials/Fundraising/` are marked accordingly and aren't yet signable. See those documents' own disclaimers before sending anything externally.
