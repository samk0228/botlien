# Robochestra (working name)

Antonio's newest venture idea, started as a coffee-chat-outreach side conversation on 2026-08-04: a simple, cross-brand workflow layer that lets a small business coordinate different types of humanoid robots, cleaning, greeting, moving, stocking, in one sequence through a single interface. The pitch analogy is Sonos for multi-room audio, or n8n for software workflows, applied to physical humanoid labor.

## What's known so far

- **Team:** Antonio D'Angelo (GTM/business) + Samuel Kim (CTO, building the backend, technical/robotics background not yet confirmed).
- **The gap identified:** enterprise fleet orchestration platforms (SapienØ, KinetIQ, InOrbit.AI) target large warehouses; home hubs (HouseBots) target consumers. Nobody found in research is building the simple, small-business-focused, cross-function version.
- **Why now:** humanoid robots just crossed from pilot to real commercial production (Ultra Robotics / Highline Commerce, 30% order fill, July 2026); $8.6B was invested into humanoid robotics startups in H1 2026 alone; ISO 21423 (multi-vendor robotics interoperability standard) is drafting for publication this year; RaaS pricing has dropped to $8-15/hr.
- **Current honest assessment:** Opportunity Meter composite 5.4/10. Real timing and urgency, but the actual SMB buyer mostly doesn't exist yet, and team/proof readiness is the weakest link for any future investor conversation.
